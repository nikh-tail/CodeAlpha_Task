# CodeAlpha Internship Tasks

# Task 1: Responsive Image Gallery

An interactive image gallery built with HTML, CSS, and Vanilla JavaScript for the **CodeAlpha** Web Development Internship.

---

### ✨ Features
* **Responsive Layout:** Clean grid design optimized for mobile, tablet, and desktop.
* **Interactive Lightbox:** Full-screen modal with Next/Previous navigation controls.
* **UI/UX Effects:** Smooth hover transitions and image zoom animations.
* **Category Filter:** Dynamic filtering by tags (Nature, Architecture, Travel).

---

### 🛠️ Tech Stack
* **HTML5** | **CSS3** (Flexbox / Grid) | **JavaScript (ES6)**

---

### 🚀 Quick Start
1. Open the `Task_1_Image_Gallery` directory.
2. Launch `index.html` in your browser.
