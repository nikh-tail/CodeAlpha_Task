## ✨ Key Highlights & Features

- 🎨 **Modern Glassmorphic UI & 3 Dynamic Themes**:
  - Seamless toggle between **Dark (Default)**, **Cyber Glow**, and **Light** modes.
  - Full `localStorage` persistence with `color-scheme` support and zero flash of unstyled content (FOUC).
  - Ambient particle canvas background responding to cursor motion with reduced-motion accessibility.
- ⚡ **Dynamic Hero & Orbiting Avatar**:
  - Interactive typewriter effect cycling through core engineering competencies.
  - Profile card with glowing ring and floating animated tech badges.
  - Real-time **"Open to Roles"** availability indicator.
- 🚀 **Interactive Projects Showcase**:
  - Filterable by **Full-Stack Apps**, **AI & Vision**, **C++ & Systems**, and **Creative & Media**.
  - Accessible native `<dialog>` project modal with smooth entry transitions, architecture specs, and live preview links.
  - Includes CodeAlpha Internship projects: *LUMINA Image Gallery, NEO-CALC Pro Calculator, AURA Music Player*.
- 📊 **Live GitHub Activity Hub**:
  - Real-time GitHub API integration fetching repository counts, stars, languages, and recent pushes from `@nikh-tail` with graceful instant caching.
- 🛠️ **Categorized Skills Matrix**:
  - Multi-tab toolkit spanning Frontend, Backend & APIs, Databases & Cloud, C++ & AI Systems, and Creative Design.
- 📬 **Interactive Contact Panel & 1-Click Clipboard**:
  - Working contact form with topic pills (*Project Collaboration, Internship, Freelance, Coffee Chat*).
  - 1-Click copy for Email (`nikhilrathorq@gmail.com`) and WhatsApp/Phone (`+91 8882949593`) with animated toast feedback.
- ⚡ **Ultra-Fast Performance**:
  - Zero heavyweight runtime frameworks or dependencies. Pure semantic HTML5, modern CSS3 with custom properties, and vanilla ES6+ JavaScript.
  - Sub-50ms First Contentful Paint (FCP) and 100% GitHub Pages native static compatibility.
